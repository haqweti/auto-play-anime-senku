<h1 align="center">Senku Ultimate Autoplay</h1>

<p align="center">
  <b>Новый уровень просмотра аниме на Senku (<a href="https://senku.one" target="_blank">senku.one</a>).</b><br>
  Скрипт, который расширяет функционал стандартного плеера: добавляет <b>автопереход серий</b>, <b>умный плейлист</b> и делает управление максимально комфортным.
</p>

  <img width="100%" alt="Senku Ultimate Autoplay Banner" src="https://github.com/user-attachments/assets/8f4fb13b-f0e9-410d-806b-f26ef78f447a" style="border-radius: 16px;" />
</p>

> [!IMPORTANT]
> Для работы скрипта вам потребуется установить расширение-менеджер: **Tampermonkey** (Chrome, Firefox, Edge) или **OrangeMonkey**. Без него скрипт не сможет запуститься в браузере.

---

## Основной функционал

| Модуль | Описание |
| :--- | :--- |
| **Автопереход** | По окончании серии скрипт сам находит и включает следующую. Зависания плеера обходятся автоматически. |
| **Плейлист** | Выдвижная панель для создания очереди из сезонов или других тайтлов. Поддерживает загрузку постеров и названий. |
| **Умный поиск** | Алгоритм ориентируется на ссылки и номера эпизодов в DOM-дереве, что позволяет находить серии даже в тайтлах со сложной структурой. |
| **Фикс паузы** | Защита от бага сайта, при котором видео сбрасывалось в начало при нажатии на паузу. |
| **Стабильный звук** | Ползунок громкости в панели и в плеере работают синхронно. Громкость не сбрасывается при переходе на новую серию. |
| **Трекинг** | Отправка фоновых запросов (heartbeat) для корректного засчитывания просмотренных серий в профиле. |
| **Интерфейс** | Панель выполнена в едином стиле с сайтом (Unbounded, blur), её можно свернуть в компактную иконку. |

## Установка

> [!IMPORTANT]
> **Важное требование для Chrome и Edge (версия 138+)**
> Чтобы скрипт мог работать, современные браузеры требуют дополнительного разрешения.
> После установки Tampermonkey или OrangeMonkey **обязательно** включите один из двух переключателей:
> 1.  В настройках самого расширения найдите и активируйте **«Allow User Scripts»** (Разрешить пользовательские скрипты).
> 2.  Либо на странице управления расширениями браузера (`chrome://extensions`) включите **«Режим разработчика» (Developer Mode)**.
> Без этого шага скрипт не сможет запуститься!

| Шаг | Действие |
| :---: | :--- |
| **1** | Установите менеджер скриптов: **Tampermonkey** или **OrangeMonkey** из магазина расширений вашего браузера. |
| **2** | **Включите разрешение «Allow User Scripts»** в настройках расширения или активируйте «Режим разработчика» в браузере (см. важное примечание выше). |
| **3** | Нажмите на зеленую кнопку **«Установить скрипт»** в самом верху этой страницы. |
| **4** | В открывшемся окне менеджера скриптов нажмите большую кнопку **«Установить»**. |
| **5** | Перейдите на сайт [`senku.one`](https://senku.one) и запустите любую серию. Панель управления появится в правом верхнем углу. Если панель не появилась, нажмите F5 на странице с плеером. |

## Процесс обновления

Скрипт поддерживает автоматическое обновление. Вам не нужно каждый раз скачивать и переустанавливать файл вручную — все новые фиксы и функции прилетают сами.

<p align="center">
  <img width="821" height="775" alt="{75866F76-FE9D-4340-830E-E27A1F54C13D}" src="https://github.com/user-attachments/assets/cc2f7603-3a2c-4981-bad1-21757c220044" />
</p>

> [!TIP]
> **Самый простой способ (Рекомендуется):**
> В 99% случаев вам вообще ничего не нужно делать. Если в настройках Tampermonkey/OrangeMonkey включена галочка **«Автоматическая установка»** (она включена по умолчанию), скрипт обновится в фоне сам, без вашего участия.

### Если пришло уведомление об обновлении

Если вы увидели, что на иконке расширения появился красный значок (или цифра), это значит, что вышла новая версия:
1. Нажмите на иконку расширения **Tampermonkey** или **OrangeMonkey**.
2. В выпадающем меню нажмите на строчку с доступным обновлением.
3. Откроется вкладка, где нужно просто нажать зеленую кнопку **«Обновить» (Update)**.

> [!NOTE]
> **Куда девается старый код?**
> При обновлении менеджер скриптов **полностью перезаписывает** старый файл на новый. Это нормальное поведение. Ваши личные настройки (сохраненная очередь, громкость, позиция панели) не пострадают, так как они хранятся отдельно в памяти браузера.

<details>
<summary><b>Ручное обновление (если автообновление не сработало)</b></summary>
<br>

Если вы хотите «пнуть» скрипт и проверить обновления прямо сейчас:
1. Нажмите на иконку расширения и выберите **«Панель управления» (Dashboard)**.
2. Перейдите на вкладку **«Утилиты» (Utilities)**.
3. Нажмите кнопку **«Проверить обновления» (Check for userscript updates)**.
4. Если появится новая версия, подтвердите установку.
</details>
