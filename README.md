# Senku Ultimate Autoplay

Расширение для сайта Senku (senku.one), которое превращает стандартный плеер в умный кинотеатр с автовоспроизведением и очередью.


> [!IMPORTANT]
> Для работы скрипта вам потребуется установить расширение-менеджер: **Tampermonkey** (Chrome, Firefox, Edge) или **OrangeMonkey**. Без него скрипт не сможет запуститься в браузере.

---

## Основной функционал

| Модуль | Описание |
| :--- | :--- |
| **Автопереход** | По окончании серии скрипт сам находит и включает следующую. Зависания плеера обходятся автоматически. |
| **Плейлист** | Выдвижная панель для создания очереди из сезонов или других тайтлов. Поддерживает загрузку постеров и названий. |
| **Умный поиск** | Алгоритм ориентируется на ссылки и номера эпизодов в DOM-дереве, что позволяет находить серии даже в тайтлах со сложной структурой. |
| **Фикс паузы** | Защита от бага сайта, при котором видео сбрасывалось в начало при нажатии на паузу. |
| **Стабильный звук** | Ползунок громкости в панели и в плеере работают синхронно. Громкость не сбрасывается при переходе на новую серию. |
| **Трекинг** | Отправка фоновых запросов (heartbeat) для корректного засчитывания просмотренных серий в профиле. |
| **Интерфейс** | Панель выполнена в едином стиле с сайтом (Unbounded, blur), её можно свернуть в компактную иконку. |

## Инструкция по использованию

<details>
<summary><b>Как установить скрипт (нажмите, чтобы развернуть)</b></summary>
<br>

1. Установите Tampermonkey или OrangeMonkey из магазина расширений вашего браузера.
2. Нажмите на кнопку **«Установить скрипт»** в самом верху этой страницы.
3. В открывшемся окне менеджера скриптов нажмите **«Установить»**.
4. Откройте `senku.one` и запустите любую серию.
</details>

<details>
<summary><b>Как настроить очередь (Плейлист)</b></summary>
<br>

1. В правом верхнем углу найдите нашу панель и нажмите на иконку списка.
2. Вставьте ссылку на страницу аниме (например, `https://senku.one/watch/1234?episode=1`).
3. Нажмите «Доб.». Скрипт подтянет название и обложку.
4. Выстраивайте элементы в нужном порядке с помощью стрелок. Когда текущий сезон закончится, скрипт перейдет к первому в списке.
</details>
