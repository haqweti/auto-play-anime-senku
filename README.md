# auto-play-anime-senku

<img width="403" height="523" alt="{EF79DA07-7606-47D0-A3A7-94A87DAF59BC}" src="https://github.com/user-attachments/assets/4282850e-5a62-47b8-91f9-52f4bc288937" />

Скрипт (UserScript) для сайта `senku.one`, автоматизирующий последовательный просмотр аниме. Добавляет панель управления рядом с плеером и позволяет непрерывно смотреть серии и сезоны с контролем уровня звука.

## Функционал

- **Автовоспроизведение:** Автоматическое включение следующей серии по завершении текущей.
- **Переход по сезонам:** Скрипт продолжает работу в конце сезона, запуская следующую часть.
- **Встроенный интерфейс:** Панель управления с настройками отображается сбоку от видеоплеера на странице аниме.
- **Контроль громкости:** Настройка максимального порога звука для комфортного фонового просмотра.
- **Логирование:** Вывод статуса работы и отладочной информации в консоль браузера.


##  Включение режима разработчика

Чтобы менеджер скриптов (Tampermonkey) мог устанавливать и запускать код, в некоторых браузерах необходимо активировать режим разработчика. Вот как это сделать в каждом из них:

### Google Chrome, Microsoft Edge, Opera, Brave, Vivaldi и другие (на Chromium)
У этих браузеров процесс почти одинаковый:

1.  **Откройте страницу управления расширениями.** Вставьте в адресную строку один из адресов:
    *   Для Chrome и большинства браузеров: `chrome://extensions`
    *   Для Edge: `edge://extensions`
    *   Для Opera: `about://extensions`
2.  **Включите режим разработчика.** Найдите переключатель «Режим разработчика» (Developer mode) и включите его:
    *   В **Chrome, Opera, Brave**: переключатель находится в **правом верхнем углу**.
    *   В **Edge**: переключатель находится на **левой боковой панели**.
3.  **Разрешите запуск скриптов (только для Chrome 138 и новее).** После включения режима разработчика, в списке расширений найдите **Tampermonkey**, нажмите «Детали» (Details) и включите переключатель **«Разрешить пользовательские скрипты»** (Allow User Scripts).

### Mozilla Firefox
В Firefox нет отдельной кнопки «Режим разработчика» для расширений. Вместо этого используется страница отладки:

1.  Вставьте в адресную строку `about:debugging` и нажмите Enter.
2.  На левой панели выберите раздел **«Это Firefox»** (This Firefox).
3.  Нажмите кнопку **«Загрузить временное дополнение»** (Load Temporary Add-on) и выберите файл вашего скрипта (`.user.js`).
4.  *Примечание:* При таком способе скрипт будет активен до перезапуска браузера. Для постоянной работы рекомендуется установить Tampermonkey из официального магазина дополнений Firefox.

###  Важно для пользователей Tampermonkey
После включения режима разработчика в браузере, обязательно проверьте настройки самого расширения Tampermonkey:
1.  Нажмите правой кнопкой мыши на иконку Tampermonkey и выберите **«Управление расширением»** (Manage Extension).
2.  Найдите и включите переключатель **«Разрешить userscript'ы»** (Allow User Scripts).

## Установка

Для работы требуется менеджер пользовательских скриптов, например [Tampermonkey](https://www.tampermonkey.net/).


<img width="484" height="242" alt="{48275A7E-EDCA-49FF-A428-4766E6E9662F}" src="https://github.com/user-attachments/assets/d3011d02-a61f-4466-99d0-35d41b4d69c3" />


1. Установите Tampermonkey в ваш браузер.
2. Нажмите на кнопку ниже, чтобы скачать файл скрипта:

[![Установить скрипт](https://img.shields.io/badge/Установить-Скрипт-brightgreen?style=for-the-badge&logo=javascript&logoColor=white)](https://raw.githubusercontent.com/haqweti/auto-play-anime-senku/refs/heads/main/Senku%20Ultimate%20Autoplay.user.js)

3. Перетащите скачанный файл `.js` в окно Tampermonkey (или откройте панель управления Tampermonkey, создайте новый скрипт и вставьте туда код).
4. Рабочий скрипт должен гореть красным на сайте

## Использование

<img width="393" height="57" alt="{5682C53E-8223-42F7-82A0-8FAE2F6DC324}" src="https://github.com/user-attachments/assets/4c2a3d3a-16f2-4ff8-bbee-bb4318d7302f" />

1. Перейдите на страницу любого аниме на сайте `senku.one`.
2. Скрипт автоматически загрузится, и сбоку от плеера появится панель управления.
3. **Важно:** Из-за политики автовоспроизведения современных браузеров (в частности Chrome), необходимо кликнуть в любое место на странице. Это даст скрипту разрешение на управление медиа-потоком.
4. Настройте параметры громкости и автоперехода в появившейся панели.
5. Работу скрипта и статус переключения серий можно отслеживать в консоли разработчика (клавиша `F12` -> вкладка `Console`).
6. По желанию добавляете в список "три полоски cбоку" любые тайтлы которые вы хотите чтобы они шли по очереди (Важно : копируете ссылку и вставляете, можете поменять порядок просмотра)
