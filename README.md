# Senku Ultimate Autoplay

Браузерное расширение для сайта Senku (senku.one), которое превращает стандартный плеер в умный кинотеатр с автовоспроизведением и очередью.


> [!IMPORTANT]
> Для работы скрипта вам потребуется установить расширение-менеджер: **Tampermonkey** (Chrome, Firefox, Edge) или **OrangeMonkey**. Без него скрипт не сможет запуститься в браузере.

---

## Основной функционал

| Модуль | Описание |
| :--- | :--- |
| **Автопереход** | По окончании серии скрипт сам находит и включает следующую. Зависания плеера обходятся автоматически. |
| **Плейлист** | Выдвижная панель для создания очереди из сезонов или других тайтлов. Поддерживает загрузку постеров и названий. |
| **Умный поиск** | Алгоритм ориентируется на ссылки и номера эпизодов в DOM-дереве, что позволяет находить серии даже в тайтлах со сложной структурой. |
| **Фикс паузы** | Защита от бага сайта, при котором видео сбрасывалось в начало при нажатии на паузу. |
| **Стабильный звук** | Ползунок громкости в панели и в плеере работают синхронно. Громкость не сбрасывается при переходе на новую серию. |
| **Трекинг** | Отправка фоновых запросов (heartbeat) для корректного засчитывания просмотренных серий в профиле. |
| **Интерфейс** | Панель выполнена в едином стиле с сайтом (Unbounded, blur), её можно свернуть в компактную иконку. |

<details>
<summary><b>Как настроить очередь (Плейлист)</b></summary>
<br>

> [!NOTE]
> Очередь позволяет смотреть сезоны подряд без вашего участия (идеально для просмотра перед сном).

| Шаг | Действие |
| :---: | :--- |
| **1** | В правом верхнем углу плеера найдите панель скрипта и нажмите на **иконку списка** (☰). |
| **2** | Вставьте ссылку на страницу аниме (например, `https://senku.one/watch/1234?episode=1`). |
| **3** | Нажмите красную кнопку **«Доб.»**. Скрипт автоматически подтянет постер и название. |
| **4** | Сортируйте элементы очереди с помощью стрелок **▲** и **▼**. Когда сезон закончится, скрипт сам включит следующий тайтл. |

</details>

## Процесс обновления

Скрипт поддерживает автоматическое обновление. Вам не нужно каждый раз скачивать и переустанавливать файл вручную — все новые фиксы и функции прилетают сами.

<p align="center">
  <img width="800" src="https://github.com/user-attachments/assets/76ad49f7-f192-437c-a12c-140922d3ca49" alt="Схема обновления скрипта" style="border-radius: 16px; box-shadow: 0 10px 30px rgba(0,0,0,0.5);" />
</p>

> [!TIP]
> **Как это работает:**
> Менеджер скриптов (Tampermonkey/OrangeMonkey) автоматически проверяет наличие новых версий на GitHub каждые 6 часов. Если вышло обновление, оно установится в фоновом режиме без вашего участия.

**Если вы хотите обновить скрипт прямо сейчас (вручную):**
1. Нажмите на иконку расширения Tampermonkey/OrangeMonkey в панели браузера.
2. Перейдите во вкладку **«Утилиты» (Utilities)**.
3. В блоке «Проверить обновления скриптов» нажмите кнопку **«Проверить обновления»**.
4. Если доступна новая версия, подтвердите установку.
